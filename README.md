# Shivang Sharma — DevOps & Cloud Portfolio

A complete local frontend using React, TypeScript, Vite, Lucide icons, and responsive CSS. Content comes from the supplied résumé and owner-provided certification list. The original neutral sidebar design is preserved, with real case studies, professional experience, and interactive architecture overviews.

One page uses native section anchors, so React Router is unnecessary. Data and reusable components are separated, dependencies are minimal, and no backend is required.

## Accessibility and interaction

- Keyboard-accessible architecture buttons with pressed states and live component notes
- Mobile navigation with Escape to close
- Visible focus indicators, semantic sections, skip link, and reduced-motion support
- Email links, clipboard success/failure feedback, and résumé download
- No decorative live telemetry, fake status indicators, skill percentages, or terminal simulation

Copy this directory's contents into the GitHub repository root. Commit `package-lock.json`; exclude `node_modules/`, `dist/`, `.vite/`, and TypeScript cache files using `.gitignore`.
